Abbaye de Sept-Fons — huit propositions

Ouvrez une version, puis donnez votre avis directement sur la page :

  1. Cliquez sur ✎ Commenter, en bas à droite.
  2. Cliquez sur l’élément de votre choix (titre, photo, menu, bouton…) : 👍 J’aime ou 👎 Je n’aime pas, et ajoutez une remarque si vous le souhaitez.
  3. Une fois terminé, cliquez sur ☰ puis Envoyer les remarques : un fichier est enregistré dans vos Téléchargements.

Ce fichier peut passer de frère en frère : chacun l’ouvre (☰ › « Ouvrir un fichier de remarques reçu »), voit les remarques des autres, ajoute les siennes et le transmet. Le bouton ◉ masque ou affiche les remarques.
